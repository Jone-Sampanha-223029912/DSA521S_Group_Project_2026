PROJECT DESCRIPTION

This project implements a Campus Service Centre Simulation
using Java.

The project demonstrates the following data structures and
algorithms:

- Queue
- Singly Linked List
- Stack
- Array
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Algorithm performance comparison

The Queue, Singly Linked List, Array Statistics and Sorting
components are integrated into the Campus Service Centre menu.

The postfix-expression Stack exercise is implemented separately.

HOW TO RUN THE PROGRAM

Requirements:

- Java Development Kit (JDK)
- A terminal, Command Prompt, or VS Code


Using VS Code:

1. Open the DSA521S_Group_Project_2026 folder in VS Code.

2. Make sure all Java source files are inside the same folder.

3. Open Main.java.

4. Run Main.java using the Java Run button.

5. The Campus Service Centre menu will appear.

6. Select an option from 1 to 11 and follow the prompts.


Using Command Prompt or Terminal:

1. Open the terminal in the project directory.

2. Compile the Java files using:

   javac *.java

3. Run the program using:

   java Main


CAMPUS SERVICE CENTRE MENU

1. Add student to waiting queue
2. Serve next student
3. Display waiting students
4. Add student service record
